# 分形树动画

一个基于P5.js的交互式分形树动画项目，展示了一个不断生长和变化的彩色分形树动画效果。

## 项目特点

- 动态生成的分形树结构
- 平滑的动画效果
- 基于递归深度的渐变色彩系统
- 使用柏林噪声创造自然的随机效果
- 响应式设计，适配不同屏幕尺寸

## 技术栈

- HTML5 Canvas
- P5.js 图形库
- 原生JavaScript
- CSS3 样式

## 实现细节

- 使用递归算法生成分形树结构
- 通过HSB颜色模式实现平滑的颜色过渡
- 利用柏林噪声函数添加自然的扰动效果
- 根据递归深度动态调整线条粗细
- 使用CSS实现优雅的视觉效果和阴影

## 如何运行

1. 克隆或下载本项目到本地
2. 使用现代浏览器（如Chrome、Firefox、Edge等）直接打开`index.html`文件
3. 或者使用本地服务器（如Live Server）运行项目

## 预览效果

- 动画会自动开始运行
- 树的形状会随时间缓慢变化
- 颜色会根据树枝的深度和角度动态改变
- 整体效果呈现出一个流畅的、有机的生长动画

## 代码结构

- `index.html`: 主页面结构
- `sketch.js`: P5.js动画逻辑
- `style.css`: 页面样式表

## 自定义设置

可以通过修改`sketch.js`中的以下参数来调整动画效果：

- `W`: 画布大小
- `Angle`: 树枝分叉角度
- `Counter`: 动画计数器
- `Tree`函数中的参数可以调整树的形状和大小

## 注意事项

- 需要稳定的网络连接以加载P5.js库
- 建议使用现代浏览器以获得最佳体验
- 动画效果可能会占用一定的CPU资源
